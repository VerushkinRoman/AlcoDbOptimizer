# Spec Delta

## Purpose

Описывает запуск AlcoDbOptimizer на Android и Desktop, поиск ключа сервисного аккаунта, инициализацию Firebase и языковую поддержку интерфейса.

## ADDED Requirements

### Requirement: Приложение работает на Android и Desktop

Один общий интерфейс и один набор операций SHALL быть доступны на Android и JVM Desktop. Платформенные различия ограничиваются запуском приложения и расположением файлов service account.

#### Scenario: Запуск на Android

- **WHEN** приложение открывается на Android
- **THEN** отображается тот же экран сканирования, что и на Desktop

#### Scenario: Запуск на Desktop

- **WHEN** приложение запускается как JVM-приложение
- **THEN** открывается окно с тем же экраном и теми же действиями

### Requirement: Service account обязателен для запуска

Приложение SHALL искать JSON-ключ сервисного аккаунта в переменной окружения `FIREBASE_CONFIG_PATH`, системном свойстве `firebase.config.path` или известных локальных путях. Если ключ не найден, запуск MUST завершаться понятной ошибкой, а не работой без Firebase.

#### Scenario: Ключ задан переменной окружения

- **WHEN** задан `FIREBASE_CONFIG_PATH`
- **THEN** приложение использует файл по этому пути

#### Scenario: Ключ отсутствует

- **WHEN** ни один из путей не содержит service account
- **THEN** приложение сообщает, где искать файл, и не запускает операции с базой

### Requirement: Firebase инициализируется до операций с базой

После старта приложение SHALL инициализировать Firebase Admin SDK. Сканирование и поиск MUST возвращать ошибку `FirebaseNotInitialized`, если инициализация не выполнена; успешная инициализация снимает блокировку с кнопок.

#### Scenario: Успешная инициализация

- **WHEN** service account корректен и Firebase доступен
- **THEN** интерфейс сообщает об успешной инициализации и разрешает сканирование

#### Scenario: Ошибка инициализации

- **WHEN** Firebase не удалось инициализировать
- **THEN** интерфейс показывает ошибку, а операции с базой остаются недоступны

### Requirement: Интерфейс локализован на русский и английский

Все пользовательские строки SHALL поставляться в русской и английской локалях. При отсутствии перевода MUST использоваться английская строка, а не технический идентификатор.

#### Scenario: Русская локаль устройства

- **WHEN** системный язык русский
- **THEN** заголовки, кнопки, диалоги и сообщения отображаются на русском

#### Scenario: Неподдерживаемая локаль

- **WHEN** системный язык не русский
- **THEN** интерфейс использует английские строки
